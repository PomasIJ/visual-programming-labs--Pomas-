# visual-programming-labs--Pomas-

Я моделировал процесс регистрации участника на научно-практическую конференцию. Основная идея в том, что участник заполняет форму, выбирает тип участия, оплачивает оргвзнос, после чего модератор проверяет заявку и система подтверждает регистрацию. Если какое-то из этапов ветвления (корректность данных, необходимость оплаты, результат транзакции) не проходит, система запрашивает повторное прохождение определённых шагов.

Вывод: я разобрался, как настроить git-репозиторий, освоил базовые команды и графическую нотацию, увидел разницу между текстовыми и бинарными форматами при версионировании. Текстовые git разбивает на строки и отслеживает изменения, а бинарные просто сравнивает и говорит, изменён ли файл. Также разобрался, какие диаграммы лучше подходят для различных задач. BPMN используется, когда нужно установить понятный стандарт того, кто и какую работу выполняет. UML нужен, чтобы показать логику выполнения конкретного процесса. Sequence показывает взаимодействие различных систем проекта во времени. Flowchart помогает наглядно описать алгоритм с условиями и ветвлениями.
